C++ RANGE-BASED FOR + std::pair + std::map — SHORT NOTES

1. What is std::pair?

std::pair is NOT a container.

It is just a TYPE that stores two values together.

Example:

    std::pair<std::string, double> p;

    p.first = "2020-01-01";
    p.second = 10.5;

So:

    p.first   -> first value
    p.second  -> second value


2. Why does std::map use std::pair?

A map stores:

    key -> value

Example:

    std::map<std::string, double> rates;

One element inside this map contains:

    date  -> price

Internally, one map element is basically:

    std::pair<const std::string, double>

So:

    pair.first   -> key   -> date
    pair.second  -> value -> price

The key is const because map keys must not be changed directly,
otherwise the map's ordering could break.


3. What is auto?

auto is NOT std::auto.
auto is a C++ keyword.

It means:

    "Compiler, figure out the type for me."

Example:

    auto x = 5;

The compiler understands:

    x is int

For a map:

    const auto& pair

the compiler figures out that pair is basically:

    const std::pair<const std::string, double>&


4. What does this mean?

    for (const auto& pair : rates)

Read it like this:

    "For every element inside rates,
     call the current element pair."

Important:

    rates -> the whole map
    pair  -> ONE current element

pair is only a variable name.
It could also be called:

    item
    element
    value

Example:

    for (const auto& item : rates)


5. Where is the "range" in range-based for?

The range is:

    rates

This:

    for (const auto& pair : rates)

means approximately:

    start at rates.begin()
    keep going until rates.end()
    move to the next element each time

So the iterator is still there conceptually.
C++ is just hiding it for you.


6. Iterator version vs range-based version

Iterator version:

    for (auto it = rates.begin(); it != rates.end(); ++it)
    {
        std::cout << it->first << " -> " << it->second << '\n';
    }

Range-based version:

    for (const auto& pair : rates)
    {
        std::cout << pair.first << " -> " << pair.second << '\n';
    }


Connection:

    rates.begin()    -> hidden
    rates.end()      -> hidden
    ++it             -> hidden
    *it              -> pair

So:

    pair is basically the current *it


7. Why it->first but pair.first?

Because:

    it

is iterator/pointer-like.

So:

    it->first

But:

    pair

is the actual current element.

So:

    pair.first


8. What do const and & mean?

In:

    const auto& pair

auto:
    compiler figures out the type

&:
    do not copy the map element;
    refer directly to the existing element

const:
    do not modify the element


9. Mental picture

Map:

    rates

    [
        ("2020-01-01", 10),
        ("2020-01-05", 20),
        ("2020-01-10", 30)
    ]

Range-based loop:

    for (const auto& pair : rates)

First loop:

    pair = ("2020-01-01", 10)

Second loop:

    pair = ("2020-01-05", 20)

Third loop:

    pair = ("2020-01-10", 30)


10. Most important thing to remember

A range-based for loop does NOT mean that pair itself is moving.

Instead:

    C++ internally moves through the container,
    and pair refers to the current element.

Think:

    hidden iterator -> current element -> pair


11. For CPP09 BitcoinExchange

You will probably have:

    std::map<std::string, double> rates;

You can print it like:

    for (const auto& pair : rates)
    {
        std::cout << pair.first
                  << " -> "
                  << pair.second
                  << '\n';
    }

Meaning:

    pair.first  -> date
    pair.second -> Bitcoin exchange rate


12. Modern C++20 alternative: structured binding

You can also write:

    for (const auto& [date, price] : rates)
    {
        std::cout << date << " -> " << price << '\n';
    }

This means exactly the same thing,
but instead of calling the current map element "pair",
C++ directly gives names to:

    pair.first  -> date
    pair.second -> price

For learning, understand pair.first / pair.second first.
Then structured bindings will feel easy.
